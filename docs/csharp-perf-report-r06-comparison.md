## 5. 报告口径说明（避免误读）

1. **同批配对**：每个比值都来自同批次交替配对（15 组），95% CI 由 bootstrap 给出；三个节点的绝对毫秒数来自各自批次，**跨批次不可直接相除**（本机同时有语言服务索引负载，绝对漂移可达 30%）。
2. **两个 Go 口径**：`Go 默认`= 出厂 `GOGC=100`；`Go@400` = 审计调优口径。两列都给出；AB62 的空转噪声异常（218.8%），该列只作参考。
3. **`project-references-*` 族**的绝对耗时对输出目录状态敏感（clean/增量步），本表只读其配对比值。
4. **启动地板**：`--version` 整进程 ~58 ms，其中 93% 发生在 Main 之前（NativeAOT 运行时/镜像初始化）→ 小负载比值含固定成本，扣除后计算比更高。
5. 本表不含工作区中途快照（AB54/AB56/AB57）的数据；这些批次仅用于开发期同二进制 A/B。
6. §3 的自报阶段数据在 `--extendedDiagnostics` 下采集，最新节点的 Check 含方法级探针调用点（约 +4%，仅诊断模式激活；普通编译只剩一次静态开关判断，AB60 配对里的 Check 与基准持平）。`Transform`/`Print` 为两遍求和，两遍并发执行时有重叠区间。
