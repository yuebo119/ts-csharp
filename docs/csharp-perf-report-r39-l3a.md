## 1. 起点：分区失衡的量化

真实工程（291 文件图，noEmit，c8）最重分区 591ms vs 理想均值 236ms（2.5 倍）。权重 dump 探针（临时 env 闸门，量后回退）定位根因：`src/api/proto.ts` 权重 7,568（NodeCount 465 + 4.5KB 文本），占总权重 0.33%，实测检查成本 439ms，占总成本 23.2%，**被低估约 70 倍**。该文件 109 行却含对 500 成员接口的映射类型，成本由类型级计算量决定，语法节点数字段上不可预测。

结论：静态重量模型（节点数 + 文本量 + 导入数）对这类文件结构性失明，任何重新标定都到不了均衡；r37「重量与检查成本近似成比例」的读数在该负载上不成立。

## 2. 变体模拟（真实每文件成本 + 真实分区归属）

| 方案 | makespan |
| --- | ---: |
| 静态现状 | 591 ms |
| 完成即偷（前端 / 偷最重剩余分区） | 610 / 594 ms（更差） |
| 全局动态（权重降序 LPT） | 590 ms（无效） |
| **纯动态共享游标（FENNEC 序）** | **460 ms（−22%）** |

纯动态胜出的机制：proto.ts 在队列中位置靠前且其之前都是廉价 lib 文件，被 grab 时落在一个近乎空闲的 checker 上。

## 3. 实施与同二进制 A/B（消除布局混淆）

实现：CheckerPool 保留分区器产出作队列序与初值属主映射，文件从共享游标动态认领；emit 侧按属主分组、每组一把租约（替代逐文件借池）。两个改动各留 `TSHARP_CLAIM` / `TSHARP_EMIT_GROUP` 闸门用于同二进制 A/B。

**相位级（确定性）**：checkPool 墙钟 0.684 → 0.571 s（**−17%**），分区离散度 3.8 倍降至 2.3 倍，check 线程总量基本不变（早前单跑 +39% 为假象）。

**端到端（真实工程全量态，同二进制交替配对）**：

| 批次 | 对数 | shipped/new 比值 | 95% CI |
| --- | ---: | ---: | --- |
| 全量态 | 13 | 1.108 | [1.022, 1.144] |
| 全量态 | 13 | 1.030 | [0.999, 1.070] |
| **全量态** | **25** | **1.006** | **[0.989, 1.028]** |
| noEmit | 13 | 1.103 | [0.804, 1.465] |

**检查相位省下的 113ms 在端到端消失**。对内核差定位：emit 尾部（full − noEmit）动态比静态多 44%（187 vs 130ms），因为 emit 的每文件借池在属主数偏斜后同属主连续段串行化（动态认领让抢到 proto.ts 的 checker 只认领 9 个文件、其余各 ~40 个）。分组 emit 补回这个缺口（1.439 → 1.020），但其自身对出厂配置无收益（CPU +3.7%）。剩余稀释来自未变动相位（Program 0.56s + Parse/Bind/Config ≈ 0.7s，占 Total 约 55%）。

## 4. 门禁中抓到的问题（保留为方法证据）

首版实现把「本轮认领但未检查（增量路径未选中）的文件」也写入属主映射，后续查询落到冷 checker，安全套件 4 个旗标越界（incremental / watch / tracing / native-command，同为 `semantic[i]` null 的 NRE）。修正为「只记录实际检查过的文件 + 增量路径保持静态分区」后回到 91/93 ⊆ 基线。该轮次同时验证了：逐字节门禁（6 夹具三方全等）在改动前后都通过，即输出等价性不是这条路线的障碍，性能才是。

## 5. 裁决与遗留

**L3-a 关闭**：端到端无可测收益，相对参考实现（静态 FENNEC 分区）分叉无正当理由，按战役纪律全额回退（`git checkout` 恢复两个文件，重建 0/0，safety 回基线）。

若未来重开，需要先解决其中之一：① 让 emit 不依赖属主计数均衡（例如 emit 借任意空闲 checker 并接受缓存变冷，或按 emit 成本重新分组）；② 找到类型级成本的静态可预测特征（本轮已证伪节点/字节/导入三族）；③ 接受只在 noEmit 场景收益（当前读数 1~10% 且噪声大，不足以立项）。

L3-b（重文件每节点成本，proto.ts 450ms）与 L4（lib 预绑定，Program time 0.267s 占 ~20%）维持待勘，均为月级/周级工程，未在本次范围内实施。
