## 5. 报告口径说明（避免误读）

1. **同批配对**：所有比值来自同批次交替配对（15 组），95% CI 由 bootstrap 给出；跨批次绝对时间不可直接相除。
2. **两个 Go 口径**：`Go 默认`= 出厂 `GOGC=100`；`Go@400` = 审计调优口径（medium/declarations 快 8~10%，巨文件 RSS +21%）。两列都给出。
3. **启动地板**：`--version` 整进程 ~54 ms 中 **93% 发生在 Main 之前**（NativeAOT 运行时/镜像初始化）。小负载比值含 C# ~55 ms、Go ~45 ms 固定成本；扣除后计算比更高（medium 报告 +93%，计算约 3.1×）。
4. **噪声**：本批 AB51 8.5%、AB52 13.5%、AB53 8.0%；同二进制对照下限 ≤1.1%。
