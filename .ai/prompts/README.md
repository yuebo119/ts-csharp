# 优化提示词集

一套用于持续发现、定价、修复本仓问题的提示词。设计前提：性能线已在 r57 收口，重新提「优化性能」会让 AI 重走 r40 到 r57 的否决路，所以提示词的第一职能是刹车，第二职能才是找活。

## 文件

| 文件 | 用途 | 模式 |
| --- | --- | --- |
| `master.md` | 主控。每次必带，定义必读、硬规则、发现维度、输出格式 | 全模式 |
| `audit-gate-effectiveness.md` | 门禁有效性审计：覆盖率、手工变异、盲区清单 | A 只读 |
| `audit-hostile-input.md` | 恶意输入抗性：守卫矩阵、语料族、差分 | A 只读 |
| `audit-concurrency-lifecycle.md` | 并发与资源：共享状态、代际失效、池归还、取消 | A 只读 |
| `audit-architecture-contracts.md` | 架构与契约：依赖方向、公开面、重复实现、死代码 | A 只读 |
| `price-performance-candidate.md` | 性能候选定价：开口清单、探针门槛、上限测算 | B 定价 |

## 使用方式

一次会话粘贴两份：`master.md` 全文，加一个专项全文。专项末尾追加一句本轮范围，例如：

> 本轮只做 `Checking` 与 `Emission` 两层，最多产出 15 条发现卡片，不修代码。

## 推荐轮次

1. **门禁有效性**先做。它不改代码，风险最低，而且它的产出决定后面所有审计的可信度：如果门禁拦不住变异，那么「改了没红」就不等于「改对了」。
2. **恶意输入**。这是本仓唯一完全没有设施的维度，也是编译器最容易被外部输入打崩的地方。
3. **并发与资源**。本仓有四个并行相位加三种长驻形态，而并发缺陷不会在单线程夹具里出现。
4. **架构与契约**。产出的是结构性债务清单，价值在于防止后续改动踩到隐藏耦合。
5. **性能定价**。只在前四轮发现「某个新负载形态确实有量级」之后再启动。

前四轮都是只读，可以背靠背跑。任何一轮出现 `[事实]` 级的崩溃或静默错结果，先修那个，再继续审计。

## 迭代机制

每轮把发现追加到 `.ai/audit-findings.md`（master §5 要求）。下一轮开工读它，避免重复审计同一面。发现卡片里的编号按轮次累加，例如 `F-003-02`。

修复走 master 的模式 C：改代码 + 门禁六项 + 前后对照。修完在 findings 里把对应条目改成 `closed`，附提交号与门禁输出行。

## 三条纪律

1. 发现卡片没有复现路径就是猜测，单独成节，不进结论。
2. 性能候选没有探针数据就是空谈，不进清单。
3. 门禁通过不等于正确，这条已经用 r44 的真实缺陷付过学费。
